PRUEBA DE ESCRITORIO - WEB

1. Abrí index.html con Chrome o Edge.
2. Subí una captura del ejercicio.
3. Tocá "Leer texto de la captura".
4. Revisá el código extraído.
5. Si el ejercicio usa input(), escribí un valor por línea.
6. Tocá "Generar prueba de escritorio".

IMPORTANTE:
- Necesita conexión a Internet la primera vez, porque carga Tesseract.js y Pyodide desde CDN.
- Está pensado para ejercicios básicos de Python.
- El OCR puede confundir símbolos, comillas o sangrías.
- La tabla muestra el estado de las variables ANTES de ejecutar cada línea.
- Tiene un límite de 500 pasos para evitar bucles infinitos.
